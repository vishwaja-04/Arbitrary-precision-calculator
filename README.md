Arbitrary Precision Calculator in C

📌 Description

The Arbitrary Precision Calculator (APC) is a C-based application designed to perform arithmetic operations on large integers that exceed the range of standard C data types. It uses doubly linked lists to store and process individual digits, enabling calculations on numbers of arbitrary length.

The calculator supports addition, subtraction, multiplication, and division through a command-line interface.

✨ Features

- Addition: Adds two large integers.
- Subtraction: Subtracts one large integer from another.
- Multiplication: Multiplies large integers.
- Division: Divides one large integer by another.
- Large Number Support: Handles integers beyond the limits of built-in C data types.
- Command-Line Interface: Accepts operands and the arithmetic operator through command-line arguments.

Technologies Used

- Language: C
- Data Structures: Doubly Linked Lists.
- Concepts: Pointers, Dynamic Memory Allocation, Command-Line Arguments, and Modular Programming.
- Compiler: GCC
